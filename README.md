# 🚗 Car Rental Management System

A **Car Rental Management System** designed to manage car listings, bookings, and users efficiently.
This project helps users rent cars easily while allowing admins/owners to manage cars and bookings.

---

## 📌 Features

* 🔐 User authentication (Login / Signup)
* 🚘 Add, update, and delete cars
* 📅 Car booking system
* 📄 View user bookings
* 🧑‍💼 Admin/Owner car management
* 📊 Dashboard for managing rentals
* 🗄️ Database integration for persistent data

---

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript / React
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Zeeshanjaved368/Car-Rental.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd Car-Rental
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run the Project

```bash
npm start
```
